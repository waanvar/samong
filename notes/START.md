# START

Samong: knowledge base แบบ local-first สำหรับโน้ต Markdown ที่อยู่ใน repo
ไบนารีเดียว (Rust) ไม่มีบัญชี ไม่มีคลาวด์ ค้นภาษาไทยด้วยการตัดคำ และมี MCP server
ให้ AI agent ทุกค่ายใช้เป็นความจำร่วม

โฟลเดอร์ `notes/` คือความจำของการทำงานบนโปรเจกต์นี้ — สิ่งที่ตัดสินใจ งานที่ค้าง
และสิ่งที่วัดมาแล้ว อ่านไฟล์นี้ก่อน แล้วตามลิงก์ไปเฉพาะที่เกี่ยวกับงาน

## กฎและสัญญา (อ่านก่อนแก้โค้ด)

- `AGENTS.md` — คำสั่งสำหรับ agent ทุกค่าย: ชุดตรวจก่อน PR, กับดักที่เคยเจอ,
  สิ่งที่จะถูกปฏิเสธ (`CLAUDE.md` แค่ import ไฟล์นี้)
- `CONTRIBUTING.md` — สัญญาว่าอะไรถึงจะถูก merge
- `docs/DESIGN.md` — ระบบดีไซน์ของ web UI อ่านก่อนแตะหน้าจอทุกครั้ง
- `docs/AI-AGENT.md` — วิธีต่อ MCP และ template โน้ต (decision / handoff / START)

## ประวัติและเหตุผล

- `PLAN.md` — บันทึกการตัดสินใจราย phase (ภาษาไทย) ทำไมถึงเป็นแบบนี้
- `CHANGELOG.md` — สิ่งที่ปล่อยแล้ว และหัวข้อ Unreleased
- `docs/RELEASE-LESSONS.md` — release ที่พังและสาเหตุ
- `docs/EVAL.md` — วิธีวัดคุณภาพการค้น และผลที่วัดจริง

## งานค้าง (handoff)

- [[open-prs]] — PR ชุด 5 พ.ย. ที่ merge แล้ว และสิ่งที่เจอระหว่างทาง (ยังไม่ได้ปล่อย release)
- [[unmerged-branches]] — branch ที่มีงานแต่ยังไม่มี PR
- [[next-features]] — ฟีเจอร์ที่เสนอแล้วยังไม่ได้ทำ พร้อมเหตุผล
- [[flaky-phase12]] — เทสต์ที่ล้มเป็นบางครั้ง

## การตัดสินใจ (decisions)

- [[provider-neutral-memory]] — ทำไมความจำต้องไม่ขึ้นกับค่าย AI
  และบทวิเคราะห์ 10 เคสที่ทำให้งานเพี้ยน

## สิ่งที่วัดมาแล้ว (findings)

- [[tokenizer-beyond-thai]] — tokenizer กับภาษาอื่นนอกจากไทย
  (CJK, Hindi, Lao, Khmer, Burmese, Vietnamese) ผลวัดจริงและทางแก้ที่เสนอ

## ร่างที่รอเจ้าของนำไปใช้ (drafts)

- [[samong-context-skill-update]] — แก้ skill `samong-context` นอก repo ที่ยังอ้าง
  v0.3.6 และเคลมว่าตัดคำญี่ปุ่น/จีนได้ (ไม่จริง)

## วิธีเขียนโน้ตใหม่ในโฟลเดอร์นี้

ตาม template ใน `docs/AI-AGENT.md` ใส่ path ของไฟล์ที่เกี่ยวข้องไว้ในเนื้อโน้ตเสมอ
และใส่คำสำคัญทั้งไทยและอังกฤษ เพราะการค้นด้วยคำเป็นการค้นคำตามตัว
repo นี้เป็น public — ห้ามใส่ค่า secret และเรื่องภายในของบริษัท
