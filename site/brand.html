Brand assets

The mark is a small network with exactly one node lit — the product's one act, drawn rather than typed. The wordmark is outlined, so nothing here needs a font installed to look right. Everything is SVG: scale it to a favicon or to a wall.

Two versions of each. The colour files are drawn in light ink for a dark ground — the product's own surface. On white, on a shirt, or in one ink, use the -mono file and set the colour yourself.

Apache-2.0 covers the code, not the name or these marks. You may use them to refer to Samong — writing about it, linking to it, saying your tool works with it. Do not use them as the identity of your own product, or on a fork you distribute under a different name.

Files

Lockup

The default. Mark, a fixed gap, then the name — mark 1.208em, gap 0.283em of the wordmark, so it holds at any size. Use this wherever there is room.

Wordmark

Outlined Bai Jamjuree 700 at a −0.04em track. The o carries the accent because it is the lit node: the name and the idea are one gesture.

Mark

Four circles, four lines. For favicons, app icons, avatars and anything under about 32px, where the name would not be legible anyway.

samong-mark.svg …-mono.svg

One colour

Every -mono file draws in currentColor: set the colour on the parent and it follows, or leave it and get black. For screen print, embroidery, engraving, laser cut, and Windows forced-colors mode — and for any light background, since the colour files are drawn in light ink for a dark ground.

Rules

Clear space

Keep the height of the mark clear on every side. Nothing crops into it — not a card edge, not another logo.

Minimum size

Lockup: 96px wide on screen, 25mm in print. Below that use the mark alone; the letters stop resolving before the circles do.

One lit node

Exactly one element wears the accent, and it is always the same node. Two lit nodes is not the logo. Neither is none.

Do not redraw

No outlines, shadows, gradients, rotation, stretching, or re-spacing the letters. Recolour only by swapping in a -mono file.

Colour

Three values do the whole job. The accent is reserved: in the product it means this is the thing you were looking for, and it should not be spent on decoration here either.
